# RPG-OOP-The_HERO_CLASS

Este repositorio contiene la arquitectura para un RPG.

## Contenido
- `main.cpp`: Todas las clases y el bucle de simulación principal.
- `UML_Diagram.png`: Diagrama de clases.

## Requisitos
- Compilador de C++.
- Compatibilidad con el estándar C++11 o superior.

## Instrucciones de Compilación y Ejecución

Abre tu terminal, busca y abre la carpeta donde clonaste este repositorio y ejecuta el comando de abajo para compilar:

`g++ -std=c++11 main.cpp -o game`

Ya compilado, ejecuta el simulador con el siguiente comando:

##En Linux / macOS:
`./game`
## En Windows:
`game.exe`
